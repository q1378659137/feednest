# FeedNest

多用户自托管 RSS/Atom 阅读器，三栏布局（订阅树 / 文章列表 / 正文），参考 Feedbro 的阅读体验。

## 特性

- 多账号登录，订阅、已读、收藏按用户隔离
- OPML 导入导出（兼容 Feedbro / Feedly / Inoreader）
- 手动 + 定时刷新，按最久未刷新轮转，源多也不会漏
- 三种列表视图、收藏、搜索、浅色/深色/护眼主题

## 使用

安装完成后访问 `http://服务器IP:13786`，默认账号 `admin` / `admin`。

**登录后请立刻在右上角头像 → 修改密码。**

新部署是空的：登录后点顶部「导入」选择自己的 OPML 文件即可。

## 数据

数据保存在应用目录下的 `data/`（SQLite），备份这个目录即可。
